# clampipv6

Clamp host/ipv6 network string helpers for config audits.

**Site:** https://theworker02.github.io/clampipv6/

## Install / run

```bash
git clone https://github.com/theworker02/clampipv6.git
cd clampipv6
node src/cli.js
node --test
```
